## 实战发现的问题与改进方向（一致性复盘）

1. **角色跨镜头漂移**：纯文本生成依靠随机潜变量，爸爸在三镜中（墨镜赤膊 → 戴眼镜白T → 摘镜入水）判若三人，女儿泳衣与面部细节脱节；后续需接入参考图先验或专用 LoRA。
2. **场景空间割裂**：岸边斜坡石阶、近景水纹与背景绿植树篱未能统一；后续需以固定全景场景底图作为空间先验。
3. **原生音频缺乏对白台词**：物理拟音强，但台词咬字无法讲清且无唇形对齐；后续建议音画解耦，外挂专业儿童 TTS 与口型同步工具。

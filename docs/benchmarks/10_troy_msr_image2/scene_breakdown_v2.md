# 木马计：夺门 · V2 场景拆解

8 场、20 镜、目标约 100 秒。前十二镜沿用 V1，后八镜改为夺门战与军团入城。当前静态分镜的细节限制见 [审阅记录](storyboard_v2/qa.md)。

| 场景 | 镜号 | 空间与调度 | 状态变化 |
| --- | --- | --- | --- |
| A 城门外：劝诱 | S01、S02 | 木马在城外；西农与守卫面对面，市民后侧观察。 | 城门敞开但受守卫控制；舱门关闭，梯子收起。 |
| B 门槛到广场：搬运 | S03、S04 | S03用低机位轮子细节过渡；S04回到广场左门、右喷泉的主地理。 | 木马仅随车轮移动；木腿、头和躯干没有动物运动。 |
| C 停驻与关门 | S05、S06 | 木马停驻位置延续日景；S06反打门内侧，装备靠墙。 | S05绳索松弛；S06城门由开到闭；舱门一直关闭。 |
| D 静场与出马 | S07、S08、S09、S10、S11、S12 | 保持同一木马侧腹和梯子轴线；喷泉在右，城门在左后方。 | 闭舱无梯 → 开舱无梯 → 放下一架梯 → 奥德修斯下梯 → 奥德修斯落地 → 随队士兵下梯。；后续伏兵陆续跟出，在S13已形成六人小队。 |

| G 门洞：军团突入 | S19 | 从门内斜看门洞，希腊队列从城外连续涌入；特洛伊守军在门内街口迎战。 | 门已开，军团进入并与守军交战，门侧被先遣队控制。 |

## 连续性与实际画面

S16/S18 原提示词要求六人，首张解闩图实际七人。本版沿用两名操作者、两名掩护希腊兵、三名特洛伊兵的七人站位，避免再拆换场景身份。切换前后完整提示词与失败初图保留。

S20 收尾聚焦普通两军军士，具名英雄画外；S13–S19 交代奥德修斯与阿伽门农的动作。原版广场大战复制了英雄，已保留并标为需修订。

闭门 → 抬闩 → 推门 → 大军通过。操作者收剑、双手可用；年轻兵背盾；奥德修斯与阿伽门农无盾。横闩仅一根，取下后设计为靠左墙；具体可见性按审阅记录判断。木马朝右原地停驻、唯一侧舱与梯子；故事旗帜纯暗红。

静态预览不能据此声称已验证多人动态、连续动作或 MSR 效果提升。

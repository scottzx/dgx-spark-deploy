# 木马计：夺门 · MSR V2 视频测试 V1

当前状态：20 镜生成与 100 秒拼接已完成，本地技术检查通过；原 FL2VA 服务已恢复 READY。

- 20 镜，每镜一个固定种子，20 × 5 秒 = 100 秒。
- LTX-2.5 原生 8 步，Licon MSR V2 与 distilled LoRA 强度各 1.0；沿用 `09_troy_climax/msr` 已验证的采样流程。
- 每镜最多 5 张独立参考：对应可见人物、群体服装、场景或道具，以及选定分镜图。人物参考保留完整竖幅，环境及分镜适配宽幅。
- 原片 768 × 448、121 帧、24 fps，交付裁去上下各 8 像素并截取前 120 帧，得到 768 × 432、5 秒。
- 独立镜头按顺序硬切，帧数重建时间戳，保留视频模型原生环境音。无对白、无配乐是生成目标，未独立听审或转写，不能保证模型完全避免语音或配乐。
- 复用已选资产与分镜，未新增云端生图；后续生图仍使用自托管 Qwen Image 2.1。

# 完整影片V3测试记录

本轮生成22条新视频，选入20镜：LTX19镜、H3辅助1镜。剪辑成片91.25秒；100秒未剪版和31.75秒战斗段保留。技术规格672×384、24fps、双声道32kHz。原始5秒素材不修改。

原计划H3负责S01/S07/S17。S01/S07提前开舱，S07还提前出现梯子，因此用新生成LTX替换；S17仅采用前1.75秒闭门待命段。没有使用旧版视频填补。

## 验证与范围

20条选片的输入指纹和输出SHA逐项匹配，全部120帧、5秒，全文件解码通过。最终91.25秒影片、31.75秒战斗段和100秒未剪版全文件解码通过。浏览器24个媒体均能读取，完整片实际播放、跳转67秒和旧版同步播放通过；分段读取返回206，解决长片进度条跳转问题。原视频服务已恢复READY，独立健康回执见[service_health_after.json](service_health_after.json)。

视觉检查为20镜共250张精确时间采样；普通镜每0.5秒采样，S15/S19/S20每0.25秒采样，并含最后一帧。所有5秒原素材均采样，包括被剪掉的尾段。记录由Codex视觉检查完成，不代表逐帧物理正确或独立人工验收。音轨完整保留且技术检查通过，未独立听审，无对白、无配乐仍是提示词目标。

## 后续改进重点

LTX连续攻防作为动作方向保留；本轮已覆盖守军拦截、近战、掩护解闩、开门、冲门与广场军团战。仍需优先修复S15长矛变形、S16门闩托架一起移动，以及S19/S20的群体接触、指挥者前进和近景可读性。当前结果完成整片测试，但没有标记为制作质量全部合格。

H3辅助镜头采用现有W8A8/FastH3-VSA四次更新预览和原生H3解码，不经过LTX精修。该预览主要蒸馏T2VA，不能从此首帧测试推断完整H3底模的上限。LTX采用BF16 dev＋distilled LoRA、8步、首帧strength1、原生LTX视频及音频VAE，没有MSR和尾帧约束。

LTX19条生成计时中位数26.89秒，含视频/音频导出和技术检查，首条还含首次调用开销。H3计时为API捕获，解码另计；不是同口径速度排名。原服务恢复预热468.7秒。监督器主LTX阶段包含补跑期间暂停，不能与补跑阶段相加。完整计时见[performance.json](performance.json)。

# 女装营销音色试听

本轮生成三种候选方向与一版柔和风格对照。A、B 为 Qwen3-TTS-12Hz-1.7B-CustomVoice / Vivian，C 与对照为 Serena。每种含同一段完整女装介绍与三个商品短句，共 16 条选定音频。音色提示、随机种子、原始 WAV 与 SHA256 均保留。

A 以热情专业导购为目标；B 以强节奏、有冲劲的直播介绍为目标；C 以中低音区、圆润饱满、自信的导购为目标。页面说明是生成目标，实际听感请以试听为准。

全部试听统一约 -23 LUFS，真实峰值保持在 -3 dBFS 以下。处理只有一致的轻微高通、3.5kHz 减 2dB 和常数增益，保留自然音高与语速，没有为了原来的视频窗口强行压缩时长。verification.json 记录实际响度、真实峰值、格式、时长、完整解码与文件哈希。

四段完整介绍的自动转写与文案相符。C 的粉色开衫短句和 B 的连衣裙短句在初次识别中出现疑点，分别重生成一次，选定版本的识别文本均匹配；初次版本和识别记录仍保留。asr_summary.json 汇总 16 条选定发音的文本检查。自动转写仅用于检查内容，音色、激情程度和是否刺耳仍需试听判断。

原三路九条视频的配音和口型尚未替换。候选短句自然时长不完全符合原 3.44 秒介绍窗口，选定音色后应同步调整介绍时长和口型。

Qwen3-TTS VoiceDesign 公共权重下载尝试因传输过慢取消，本轮未使用该模型出音频；部分下载缓存保留，见 design_download_attempt.json。

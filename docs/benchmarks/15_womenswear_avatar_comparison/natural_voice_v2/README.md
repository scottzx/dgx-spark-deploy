# 女装自然语气试听

本轮尝试减少表演性风格约束，使用口语化女装文案。三版均来自本地 Qwen3-TTS-12Hz-1.7B-CustomVoice：1 为 Serena 默认语气，2 为 Serena 加一句简短聊天提示，3 为 Vivian 默认语气。三版完整口语介绍使用相同文案和配对随机种子；保留完整提示、原始 WAV 与文件哈希。

每版原始生成一段完整口语介绍、一段旧营销文案对照和三个商品短句，共 15 条选定生成音频。页面展示三段完整介绍、九条短句、两段通过读词检查的同词对照，并另提供上一轮成熟带货风格的原始配音。1、3 的同词对照与上一轮使用相同文案；2 的旧文案对照识别有疑点，保留在文件中，未作为试听对照展示。两次尝试的原始输出保留。

三段完整口语介绍和所有展示的短句及同词对照，自动转写与文案匹配。1 的连衣裙短句初次识别在句尾有疑点，保留默认语气、只换随机种子重生成一次后匹配。ASR 只能辅助检查内容，不能证明自然度或代替实际试听。

声音统一约 -23 LUFS，峰值低于 -3 dBFS；只做一致的轻微高通、3.5kHz 减 2dB 和常数增益，没有变调或加速。verification.json 包含 15 条新配音和 1 条复用对照的媒体记录。原三路视频配音与口型尚未更新。

# 三件女装：三条数字人路线实测

日期：2026-10-08。任务是同一位虚构成年主播，逐件完成「从画面外接过衣服 → 手持展示介绍 → 递回画面外并松手」。

[打开竖屏对比页](review.html) · [实际结果与逐件观察](results_summary.md)。三条路线为 InfiniteTalk、LongCat-Video-Avatar 1.5、LTX-2.5＋LatentSync 1.6，每条路线各三件，九条候选成片全部完成，另提供三条顺序合辑。页面只展示实际推理完成并通过媒体验证的结果；最新完成数见 progress.json，实际推理记录见 measured_results.json。

## 商品与共同输入

| 商品 | 展示特征 | 同源 Serena 中文配音 |
| --- | --- | --- |
| 白色衬衫 | 白色、长袖、翻领、纽扣 | 白色衬衫，简洁利落，通勤好搭。 |
| 粉色针织开衫 | 浅粉色、长袖、V 领、针织、纽扣 | 粉色开衫，温柔百搭，适合叠穿。 |
| 黑色连衣裙 | 黑色、短袖、圆领、A 字裙、腰线 | 黑色连衣裙，线条简洁，日常好搭。 |

商品是测试用生成款式，没有对应实际销售 SKU。服装参考素材由内置 image_gen 生成；最终素材、完整提示和 SHA256 保存在 assets/manifest.json 与 assets/image_prompts.json。初期横屏构图保存在 assets/landscape_draft，仅供记录；用户随后明确选择 3:4，正式模型输入使用重新构图的竖屏素材。

正式参考图为 1086×1448，精确 3:4；三条路线目标原生视频尺寸均为 576×768、25 FPS。每件统一成片 201 帧、8.04 秒。配音由本地 Qwen3-TTS / Serena 生成，2.4 秒开始，约 5.85 秒结束；保留原始音频与处理记录。三个模型使用同一份 24 kHz 成片配音，需要时以同源 16 kHz 副本驱动。

约前 2.4 秒接衣服，中段介绍，约最后 2.2 秒递回。只有本轮正在介绍的一件衣服进入画面，其余两件在画面外等待。衣服悬挂在木衣架上，助手白色袖口的手从画面右侧进入交接。主播穿红色上衣，便于区分身上的衣服和手持商品。

## 路线与约束差异

- **LTX-2.5＋LatentSync 1.6**：LTX-2.5 dev 22B＋distilled LoRA，8 步生成完整动作。六个图像条件对应第 0 / 32 / 64 / 136 / 168 / 200 帧：空手、交接、持衣、持衣、递回交接、空手。图片是扩散条件，没有后插端点、倒放或商品贴图。LatentSync 用 20 步、CFG 1.5 匹配口型，保留完整 LTX 身体与服装动作。报告分别记录动作生成和口型耗时。
- **InfiniteTalk**：沿用已跑通的 Wan2.1 14B＋InfiniteTalk single＋FusionX LoRA 8 步路线；81 帧分段、9 帧历史条件。保留官方 demo 默认的颜色校正（强度 1.0），原生输出包含该步骤，耗时也计入单件推理。LTX 动作视频作为参考，官方 streaming 路线实际取第 0 / 72 / 144 帧（0 / 2.88 / 5.76 秒）作为稀疏图像条件，动作重新生成。最后的递回与空手关键帧没有直接传给该默认稀疏路径。文字提示均在 512 tokens 内，核对见 infinitetalk_prompt_token_audit.json。
- **LongCat-Video-Avatar 1.5**：同一个 LTX 首帧、完整时间分段提示和同源配音；Whisper large-v3、DMD 8 步，93 帧首段与两段续接，原生共 253 帧、10.12 秒。原生完整视频保留，统一对比取前 8.04 秒。中间衣服参考图没有直接作为 LongCat 条件，款式由共同提示描述约束。UMT5 提示词长度分别为 476 / 483 / 486 tokens，均未超过 512，核对见 prompt_token_audit.json。

两个美团模型的尺寸选择适配为精确 3:4，尺寸满足其空间倍数要求，避免自动选择相近比例后裁切交接边缘。官方代码与依赖沿用上一轮独立环境，修改范围见 runner_adaptations.json。三路使用不同强度的动作条件，结果不能直接解释为相同约束下的模型能力排名。

## 验收与证据

生成完成不等于动作通过。逐件检查：

1. 衣服和衣架从右侧边界进入，能够看到接触、移交和助手退手，商品没有从空白处凭空长出。
2. 展示时只有一件商品和一个衣架，颜色、袖型、领口及轮廓连续，商品不与主播红色上衣融合。
3. 手指、衣架和布料接触合理，布料自然悬垂，衣服不穿手、穿身。
4. 介绍完成后递回同一件商品，助手抓稳后主播明确松手，商品从边界退出，末段双手空着；不能只凭一个被端点约束的空手末帧判定通过。
5. 开口、收口附近检查连续原始帧，避免人物或头部突然跳变；单帧闭嘴不能据此断言口型延迟，完整音节同步需要连续播放判断。

动作帧、语音边界帧与续接位置连续帧仅提取、裁切、缩放、拼排，没有生成修补。LongCat 续接位置为第 93 / 173 帧（3.72 / 6.92 秒），InfiniteTalk 为第 81 / 153 帧（3.24 / 6.12 秒），按官方拼接步长定位。verification.json 记录完整解码、原生尺寸、帧数、时长和 SHA256，audio_verification.json 记录同一商品各路线解码 PCM 是否一致。所有失败或异常输出保留，不能用另一模型成片替换。

每条路线的三件合辑为 24.12 秒顺序剪辑，没有把它当作一次生成的 24 秒连续视频。页面支持多路同步播放，仅播放一份共用配音。原生完整视频的播放版复制原有视频码流，仅追加同源 Serena 配音；原始模型文件仍独立保留并可下载，见每组 native_playback.json。原生超时片段完整保留；精确 200 帧、8.00 秒的输出仅把真实末帧延长显示 40 毫秒，页面和测量记录明确标注。

## 执行环境

DGX Spark GB10，GPU 按共同文件锁串行运行，复用上一轮本地官方权重。任务目录 /home/admin/womenswear-avatar-tests 与旧可乐实验隔离，共用 sources、deps、compat 和模型缓存。此前暂停的业务服务没有重启。本轮验证离线服装口播与交接效果，不含实时推流链路。

本地可复现脚本位于 scripts/04_test_benchmark/womenswear_trials；adapt_runners.py 复制上一轮官方推理适配器并声明尺寸与断点续跑修改，run_queue.py 按配音、提示缓存、动作、LatentSync、LongCat、InfiniteTalk 顺序运行。watch.py 只收集有完成测量记录的结果并刷新对比页。全部九条已生成并完成逐件观察；verify_complete.py 核验 33 份视频媒体、共同输入与音轨、七张竖屏参考图以及结果记录，输出 completion_summary.json。

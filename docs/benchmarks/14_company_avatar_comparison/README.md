# 六项公司数字人项目：三组商品实测

日期：2026-10-08。六项项目包含京东 JoyHallo / JoyVASA 两种模型，实际为七种模型、21 个商品测试。

[打开对比页](review.html)（当前本地预览：http://127.0.0.1:58123/review.html）。页面只展示实际推理完成并验证的成片。

本轮建议优先保留 LTX 商品动作，以 LatentSync 1.6 处理口型；LivePortrait 可作已有口播视频驱动的备选。LongCat、InfiniteTalk、Avatar-Forever 重新生成动作时没有在三组中稳定完成完整商品流程。JoyHallo、JoyVASA 的肖像口播范围无法满足拿放商品要求。

## 共同输入与验收目标

原味、健怡、零度各 8.04 秒、25 FPS、201 帧。每组目标为「拿起商品 → 手持介绍 → 放回并松手」。使用同一套 Serena 柔和中文女声，成片统一混入原始 24 kHz 配音。16 kHz 音频是部分模型需要的输入副本。

动作参照为此前 LTX 生成视频，用户明确同意沿用；本轮没有实拍素材。图生视频模型使用对应视频的首帧。JoyHallo 为符合其肖像输入要求，另做固定身份的面部裁切；该结果仅评价口播。LivePortrait 由此前 Serena/MuseTalk 成片驱动面部，因此不是独立的音频转动作模型。

首帧、视频和音频派生记录见 [共同输入](input_manifest.json)、[派生输入](derived_inputs.json)。基线本身已有包装文字错乱；新模型沿用这些画面时，不能把既有错字算成新模型生成的问题，也不能宣称包装正确。

InfiniteTalk 官方 streaming 实现每段取 LTX 视频的一张关键帧作为图像条件，并用前一段生成结果的 9 帧续接。当前 81 帧分段的关键帧位置为 0 / 72 / 144 帧（0 / 2.88 / 5.76 秒），身体和商品动作仍由模型重新生成。

## 画面检查记录

- **LivePortrait**：三组持罐与放回关键帧保留 LTX 身体与商品动作；开口、收口附近的连续帧未见人物或头部突然切换。它以已有 MuseTalk 口播视频驱动面部，效果不能视为独立中文音频驱动能力，也没有据此判定所有音节精确同步。
- **LatentSync 1.6**：三组持罐与结束关键帧保留 LTX 商品动作；开口、收口附近的连续帧未见人物或头部突然切换。原味约 2.52 秒开始张口，音频 2.48 秒附近开始明显起声，不能将更早的闭嘴帧直接判为明显延迟。未据此判定整段所有音节精确同步。
- **LongCat-Video-Avatar 1.5**：原味与零度出现额外商品，放回后变成四罐。健怡保持三罐，拿起、手持与放回基本成立；原生末帧双手仍接触商品，未见明确离手画面。三组各生成约 20 分钟，完整商品流程没有稳定通过。 三组开口、收口连续帧未见人物或头部突然切换，未据此判定整段音节同步。
- **InfiniteTalk FusionX 8-step**：三组各生成约 52–53 分钟，完整商品流程均未通过。原味拿错中间银罐，后半段出现额外红罐，结束仍手持；健怡拿对中间银罐、检查帧保持三罐，但结束仍手持，没有放回；零度先拿中间银罐，中段放回后又举右侧红罐，结束仍手持。三组开口、收口附近连续帧未见人物或头部突然切换，未据此判定整段音节同步。
- **JoyVASA**：三组生成约 15–22 秒，能驱动口型，但属于静态肖像路线，身体与商品沿用首帧，没有拿起、手持介绍、放回动作。三组开口、收口五帧检查未见人物或头部突然切换；原味、健怡眼睛与嘴部表情偏夸张。未据此判定所有音节同步。
- **Avatar-Forever**：三组生成约 72–127 秒，动作与口播表现不一致。原味拿起左侧红罐后较早放回，结束又接触中间银罐；原味说话段的抽样连续帧持续闭嘴。健怡检查帧未见清楚离桌手持动作，开口、收口五帧嘴部基本闭合。零度有拿起右侧红罐、放回与明确离手，也能张口，但介绍尚未结束就放回。三组说话边界五帧未见人物或头部突然切换。
- **JoyHallo**：三组各生成约 16.5 分钟，仅为面部肖像口播，无法完成商品拿放。原味、健怡在第 64 帧的 16 帧分段边缘出现眼睛、嘴部及面部纹理较突兀的变化；零度该位置口型变化幅度也较大。本次没有判为连续性通过。人物外观与基线有差异，表情变化偏大，未据此判定所有音节同步。
- **Avatar-Forever（官方默认关闭历史特征缓存）**：按官方默认关闭历史特征缓存补测三组，生成约 97–105 秒。原味、健怡说话段抽样仍基本闭嘴，关闭该开关未解决口播问题。原味举起左侧红罐并较早放回，结束又双手握中间银罐；健怡检查帧未见明确离桌持罐介绍；零度能拿起右侧红罐、放回、离手并有口型活动，但较早放回、后半段空手讲述。三组没有稳定完成完整商品流程。开口、收口五帧未见人物突然切换，未判定所有音节同步。
- **Avatar-Forever（作者默认口播提示词）**：原味组采用作者默认口播提示词、关闭历史特征缓存，生成约 104 秒，2.56–4.64 秒抽样可见明显口型变化，优于同缓存设置下的商品提示词对照。开口附近手靠近嘴部，视线偏离镜头；开口、收口五帧未见人物突然切换。该条没有拿放商品要求，不能当作带货动作通过；未判定整段音节精确同步。

动作关键帧和说话边界的连续原始帧在对比页中。帧图仅做裁切、缩放和拼排，没有补帧或生成修图。单帧闭嘴不能用于判定口型延迟；需要结合实际人声起点和连续播放。

统一成片通常为 201 帧；原生 200 帧、8.00 秒的个别输出，仅延长真实末帧显示 40 毫秒以统一播放时长。当前记录：infinitetalk/original、infinitetalk/diet、infinitetalk/zero。原生输出及原始封装记录均保留，动作验收使用原生画面。松手判断要求明确离手画面，见 [验收依据](acceptance_criteria.json)。

## 环境与可复现性

DGX Spark GB10，ARM64，128 GB 标称统一内存，Python 3.12、PyTorch 2.14.1 / CUDA 13。模型串行占用 GPU。官方代码提交及依赖版本见 [环境记录](environment.json)。

所有模型使用实际官方权重；下载清单与校验见 modelscope_manifest.json、hf_manifest.json、infinitetalk_lora_manifest.json 及相应 download_receipt。适配文件位于仓库 scripts/04_test_benchmark/company_avatar_trials，原始源码保存在 Spark 的 /home/admin/avatar-company-tests/sources。

ARM64 环境使用 OpenCV / FFmpeg 实现 decord 读取接口，ONNX 面部检测使用 CPU 四线程。LongCat / InfiniteTalk 等需要的 FlashAttention 接口由 PyTorch SDPA 执行同等密集注意力；它不代表原生 FlashAttention 内核的性能。BF16 数值核对记录见 [注意力适配验证](attention_compatibility.json)。LatentSync 使用独立 Diffusers 0.32.2 目录；其他依赖也独立安装，没有改动原有业务环境。

JoyHallo 的三组官方人脸预处理已在 CPU 上实际执行，特征与遮罩记录见 [预处理检查](preflight_joyhallo_image.json)；这项检查不计入视频生成完成数。

每条成片 SHA256 与 Spark 原始记录一致，完整解码、帧数、时长、音轨验证见 [媒体验证](verification.json)。候选音轨与对应 Serena 基线的解码 PCM 逐样本一致性见 [配音验证](audio_verification.json)。每组原生输出和完整日志保留在 Spark /home/admin/avatar-company-tests/outputs 与 logs。没有以其他模型的成片替代失败或待运行结果。

本轮验证离线商品口播效果和单机生成时间，未测试 RTMP 推流、多人交互或实时直播链路。

## Avatar-Forever 默认缓存配置与口播对照

另有四条补充视频，独立于 21 条主测试：[三组缓存与作者提示词对照](avatarforever_diagnostics.html)。官方脚本默认关闭历史特征缓存，先按这个设置补测三组商品，只改变该缓存开关；再用原味音频配合作者默认口播提示词，不要求拿放商品。不能将仅口播对照当作完整商品动作通过。参数及默认值核对见 [参数记录](avatarforever_parameter_audit.json)。

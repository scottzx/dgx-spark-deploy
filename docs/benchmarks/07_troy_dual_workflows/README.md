# 特洛伊决斗：Sol-H3 双工作流实测

2026-10-03，在 DGX Spark GB10 上运行 MiniMax-H3 W8A8 + LTX-2.5。画面采用邵氏武侠摄影方向：棚景、琥珀色硬光、青色夜景阴影、舞台化打斗和快速推镜。布景是特洛伊木马，两名成年希腊武士进行无血腥决斗。样片用于验证工作流，不是完整电影。

| 分镜版 | 独立开场 + 独立动作插镜 | 10.083 秒 / 242 帧 | [播放](troy_storyboard.mp4) |
| 连续纪实版 | 同一开场 + 音视频潜变量续拍 | 9.292 秒 / 223 帧 | [播放](troy_continuous.mp4) |

全部成片为 1344×768、24 fps、32 kHz 立体声；FFprobe 检查准确帧数，FFmpeg 完整解码成功。拼接以交付帧数和对应音频采样数重新计算时间戳，避免 AAC 尾部填充导致补帧。

## 实际生成

| 片段 | 模式 | Qwen / H3 / LTX 秒数 | 请求总时长 | 交付帧数 |
|---|---|---|---|---|
| 开场 | independent | 2.82 / 55.05 / 34.59 | 94.41 秒 | 121 |
| 接续 | continue | 2.13 / 40.66 / 34.72 | 79.26 秒 | 102 |
| 新角度 | independent | 2.14 / 35.08 / 35.20 | 73.24 秒 | 121 |
| 从续拍再次接续 | continue，名义 10 秒 | 2.10 / 64.71 / 189.03 | 257.75 秒 | 222 |

首次模型预热 501.12 秒，与表内请求时间分开。两版共用开场，第二段分别独立生成或接续；接续后再独立生成，确认独立请求没有遗留上下文。

加长测试沿同一常驻会话从续拍片段再次接续，新增 222 帧 / 9.25 秒，H3 条件冻结审计通过。首次使用 10 秒画布时 LTX 产生额外编译开销；257.75 秒是该请求实测，不是稳定态速度承诺。`extension.json` 保存本次结果。

部署精确帧数拼接修正后重载服务，预热 478.66 秒。随后单个 `/api/story` 请求实跑独立 → 接续 → 独立，三个片段总耗时分别 77.59、66.03、59.85 秒；续拍的上下文冻结检查通过，后续独立镜头没有前驱或续拍上下文。最终成片严格等于 121+102+121=344 帧，完整解码通过。`mixed_story.json` 保存实际 GPU 运行和拼接结果。

默认 22 帧视频上下文、24 帧音频上下文。H3 124 帧精修为 121 帧，接续裁掉 19 帧重叠，实际新增 102 帧。因此两次名义 5 秒生成的续拍成片短于两次独立生成。审计确认 1764 个视频条件行、80 个音频条件行在 H3 去噪前后逐值相同。

## 接缝观察

续拍基本保留两个人物、木马、火盆和全景构图，后半段继续发生攻击与格挡。独立插镜有明显的重新布置和快速推近。续拍仍存在蓝衣人物的服装细节变化及镜头位置偏移，前半段动作较弱，不能宣称无缝长镜头。

[接缝测量](seam_metrics.json)中，续拍的接缝像素平均绝对差为 0.0592，独立切镜为 0.0998；同一开场最后两帧为 0.0066。续拍虽然变化较小，接缝仍明显大于正常相邻帧。该指标受动作、光线影响，不是感知质量分数。

接缝前后 50 ms 音频的归一化 RMS 变化为续拍 0.012、独立 0.571；原始 PCM 重叠窗相关性为 0.754，峰值时移为 0 ms。声学数值仅描述本样本，不等于主观听感无缝。

## 验证范围

- 65 项原有 CPU 回归测试、4 项真实 FastVideo packing ABI 的上下文测试通过。
- 3 项 `/api/story` 路由集成测试通过：混合独立/接续/独立、旧版尾帧串联、首镜非法接续。生成器在路由测试中使用替身，拼接和媒体检查使用真实成片与 FFmpeg。
- 七个片段通过常驻 API 实际 GPU 生成；非法前驱和独立镜头携带前驱返回 400。5 秒前驱→10 秒续拍、连续多段接续、单次故事请求内混合模式已实测，10 秒前驱的裁剪几何仅完成 CPU 检查。
- `comparison.json`、请求和响应 JSON 保存实际服务路径、耗时与冻结条件审计。

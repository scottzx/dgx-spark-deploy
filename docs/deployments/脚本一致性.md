## 复核

在本地仓库根目录运行：

```bash
python3 scripts/05_ops/check_deployment_consistency.py \
  --output /tmp/dxg-deployment-consistency.json
```

检查器只读：向 origin 查询 `main` 的实际提交，比较本地 HEAD、origin 跟踪引用、远程 HEAD；对仓库内所有受管脚本、技能文件及清单引用的其他源文件核对 SHA-256 与可执行位，再核对运行目录副本和本地重复文件。任何缺失、内容/执行位漂移、相关未提交修改或提交不一致都会返回非零退出码。JSON 保存逐文件证据。

若 origin 查询失败或本地跟踪引用落后，应先解决连接并执行 `git fetch origin`，再复核。`--skip-origin-network` 只用于离线排查，不能作为最终三端一致性证明。

以后更新部署脚本时，先审查远程差异并备份，提交并推送到 origin，然后将远程仓库快进到同一提交，并依据清单更新安装副本；以检查器成功退出作为文件一致性的验收。文件一致性不等同于已运行进程重载了新代码。

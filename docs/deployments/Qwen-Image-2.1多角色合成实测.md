# Qwen-Image-2.1 多角色合成实测

日期：2026-09-29。DGX Spark / GB10 / 128 GB 统一内存。

## 设计

先用 Diffusers 原版 BF16、40 步生成五个独立透明角色（男、女、小孩、猫、狗），以及三个不透明背景（室内、操场、海边）。角色为 768×1024；背景和合成输出为 1344×768。

三种合成配置分别为动态 Viggle Turbo v0.2.1 六步 LoRA、关闭适配器后的 Diffusers 原版 40 步常驻、SGLang 原生后端原版 40 步。所有配置共享完全相同的 8 张素材；每次输入 6 张原始 PNG，顺序固定为男、女、小孩、猫、狗、背景。相同场景使用相同提示词、种子和尺寸。没有人工抠图、预先拼贴或合成后修图。

本轮针对多参考图身份保持和构图能力，每个配置、场景仅一张，共 8 张素材＋9 张合成。没有为复杂合成单独预热，也没有重复抽图或挑选较好结果。单次耗时不能作为稳定性能中位数，也不能据此估计总体成功率。

Diffusers 计时包括参考图/文本编码、去噪和解码，不含 PNG 编码；SGLang 为 HTTP 总耗时，包含 PNG 编码与传输。均排除模型加载；SGLang 保留默认条件缓存，后续场景可复用部分角色条件。两者计时边界并不完全相同。

- 目视验收关注人数与宠物数量、身份/服装/毛色、比例与肢体、背景保持、接地和光照。人脸身份保持仅为人工目视判断，不是识别模型评分。

## 结果

共 17 张原始 PNG 已完成，逐张 SHA-256、尺寸、透明通道及九次合成的参考图哈希核验通过；八张素材和九张合成均已逐张目视检查。结构检查通过不等于语义完全合格。

| 场景 | Turbo 六步 | Diffusers 原版四十步 | SGLang 原版四十步 |
| --- | ---: | ---: | ---: |
| 室内 | 33.16 秒 | 98.24 秒 | 80.18 秒 |
| 操场 | 32.95 秒 | 98.49 秒 | 78.44 秒 |
| 海边 | 32.91 秒 | 98.18 秒 | 78.82 秒 |

三张合成总耗时：Turbo 99.02 秒，Diffusers 原版 294.91 秒，SGLang 237.45 秒；Turbo 相对 Diffusers 原版约快 2.98 倍。SGLang 在本轮仅约快 1.24 倍，不能沿用上一轮简单编辑的加速倍数。

共享素材：五个角色每张约 39–40 秒，三个背景每张约 53 秒，八张合计 355.53 秒。Diffusers 模型加载另计 191.88 秒。六参考图合成的峰值 CUDA 分配约 50.29 GiB；包含禁用或启用的 LoRA 权重，不能作为纯原版最低内存要求。

## 画面观察

- **主体完整性**：九张均能看到男主、女主、小孩、猫和狗，没有漏掉主要角色；眼镜、绿/红/黄服装、宠物毛色和项圈等主要特征保留。
- **人物一致性**：整体可辨认为同一组参考角色，但小孩脸型、表情、身形以及男主大小仍有变化。SGLang 和 Diffusers 原版之间也有可见变化，不能把后端差异理解为仅有不可察觉的像素误差。这里没有使用人脸识别评分。
- **姿态**：Turbo 的三张猫均呈坐姿；原版与 SGLang 的操场猫呈站姿，偏离提示词。不能据此声称四十步在所有指令上更好。
- **背景**：客厅的左窗、沙发、右书柜，以及操场布局、海岸线和右侧礁石基本保持。两个户外底图虽然要求无人，仍出现人物。三种方式清除了海边原有人群，操场近处人物被替换，但远处仍有人影，因此操场全画面恰好三个人的要求不合格。
- **融合感**：接地位置和阴影整体可用，户外主体仍有正面棚拍的感觉，与背景侧向阳光的协调不完全自然；目前只能视为可用草稿，不能认定达到所有成片要求。

这组样本支持继续把 Turbo 用作快速合成候选，未看到原版三倍耗时带来稳定、明显的质量优势。视频资产生产应先验收角色和背景，再验收合成的人数、身份、动作和光照。身份要求更高时仍需增加多种子、多姿态和实际图生视频验证；本轮没有执行这些测试。

本地 `comparison.html` 展示全部 17 张原图和逐张观察，支持点击放大。浏览器工具阻止访问本地 file URL，未进行页面渲染与点击验收；原始 PNG 已直接查看，HTML 的资源引用通过静态检查。


SGLang 启动至健康就绪 68.03 秒，单独计时。测试服务已退出，原语言服务恢复，8000/8001 健康检查均为 `ok`。
